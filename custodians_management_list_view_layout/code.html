About Custodian Management

Custodians are individuals identified as having relevant data for discovery. The system automatically syncs these from Active Directory. Use the Bulk Merge tool if you find multiple accounts (e.g., admin and standard user) belonging to the same physical person to ensure all data is tracked under a single identity.
